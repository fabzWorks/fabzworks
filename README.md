# FabzWorks Website

A Next.js (App Router) + TypeScript + Tailwind CSS marketing site for
FabzWorks, an IT services company (ERP, CRM, web, mobile, AI, automation,
integrations, and custom software).

Fully functional on static data — every service, team member, blog post,
job listing, and case study is clickable and opens a real detail view.
Includes dark/light mode with 4 accent themes, a working (demo) auth flow,
a job-application flow, and a Resend-ready contact form.

**Start here:** [`docs/PROJECT_GUIDE.md`](./docs/PROJECT_GUIDE.md) — a
beginner-friendly explanation of the whole codebase, how the modal routing
works, where content lives, and how to connect a real backend later.

## Quick start

```bash
npm install
npm run dev
```

Open http://localhost:3000.
